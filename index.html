📖 Tuto

Suis les étapes ci-dessous pour installer et lancer un jeu correctement.

▶ Voir la vidéo tuto

📦 Étape 1 — Installer WinRAR

WinRAR permet d'extraire les fichiers compressés (.rar, .zip) des jeux téléchargés.

  1. Va sur winrar.com et télécharge la version Windows.
  2. Ouvre le fichier téléchargé et clique sur Installer.
  3. Laisse tout par défaut et clique sur OK.
  4. WinRAR est maintenant installé sur ton PC.

🎮 Étape 2 — Extraire et lancer le jeu

Une fois le jeu téléchargé sous forme de fichier compressé :

  1. Fais un clic droit sur le fichier du jeu (.rar ou .zip).
  2. Clique sur Extraire ici ou Extraire dans un dossier.
  3. Ouvre le dossier extrait.
  4. Cherche le fichier qui se termine par .exe (c'est le lanceur du jeu).
  5. Double-clique dessus pour lancer le jeu.
